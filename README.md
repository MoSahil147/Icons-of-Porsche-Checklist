# Icons of Porsche 2026 Fan Field Guide

A fan-made Icons of Porsche 2026 field guide. The site is designed for visitors who already have a ticket, with a clear checklist, possible keepsakes, Porsche facts, and one secondary link to the official ticket registration page.

The page reads like a building-instruction sheet. Each tick adds a part to a brick-built Porsche 911 Carrera (992) at 1:12 scale, so the model is the progress meter. The hero model and the build model come from the real side outline of the car. The engine section shows a flat-six from above, driven by one crank angle in the true firing order. This is an independent fan project, not an official Porsche or LEGO collaboration.

## Run locally

This is a static website with no build step, backend or database. The page itself needs no package install; only the tests do. Sharing and the offline cache need `localhost` or HTTPS, so serve the folder:

```sh
bunx --bun serve .
bun install
bun test
bun run e2e
bun tools/check-text.js
```

`bun test` checks the plan link, the paint swap, the item order, the asset versions and the site files. `bun run e2e` runs the browser journeys in Chrome or Chromium (set `CHROME_PATH` if it is not found), axe included; `tools/e2e/BEHAVIOUR.md` maps each feature to its journey. `tools/check-text.js` fails on em dashes, en dashes and emoji. CI runs all of these, validates `index.html` and deploys to GitHub Pages from `main`.

## Checklist behaviour

Checklist progress saves in the visitor's browser under the existing `brick-by-brick-iop26-v1` local storage key. Saturday and Sunday are stored separately. The selected day and checklist category also return after a refresh. The combined view lets a visitor update each day independently. The reset controls use a confirmation dialog. If browser storage is unavailable, the checklist remains usable for the open page and explains that ticks will not persist after refresh.

## Files

- `index.html` contains the page content, the checklist, the inline build model and the engine drawing.
- `styles.css` contains the layout and components. `tokens.css` holds the colour, type and spacing tokens. `base.css` holds the base rules.
- `js/` holds the page script as ES modules, one per job, loaded with `<script type="module">` and no build step: `state.js` (saved list, paint and name), `checklist.js` (ticks, days, progress, build model, part flight, reset), `story.js` (story image and share), `paint.js` (paint picker, repaint and tooltip), `link.js` (plan link and banner), `engine.js`, `rail.js` (exhaust), `segment.js` (the sliding thumb on the day and list switches) and `main.js` (start-up and the service worker).
- `plan.js` holds the plan-link codec and the paint swap. The page and `bun test` both import it.
- `sw.js` keeps the site available with no signal after one visit. It fetches from the network first and falls back to the cache after 3 seconds.
- `fonts/` holds League Spartan and Onest (latin subset, SIL OFL 1.1, licences included). `icons/` and `manifest.webmanifest` give the favicons and the home-screen icon.
- `og-v3.png` is the link preview image for WhatsApp and other apps, 1200 x 630: eight cars, one per paint, on an arc around the headline and the event date.
- `sports-car.svg` is original fan art: the brick-built 911, generated by `tools/build-car.js`.
- The scroll rail (wide screens only) shows a small 911 that drives down the page and takes the eight paints in turn. CSS scroll-driven animations move it and wipe on each paint, so no script runs per frame. A firm flick of the wheel or trackpad makes exhaust puffs; keys and links do not. With reduced motion, or where the browser has no `animation-timeline`, the rail does not show.
- The car cursor is an experiment. By default it shows over the hero car and the paint swatches, with a mouse only. To try other scopes, set `data-cursor` on `<html>` in DevTools: `all` (all but text and controls), `links` (links and buttons) or `off`.
- `tools/car-profile.json` is the side outline of the 992 Carrera, traced from a scaled side elevation on dimensions.com.

## Sharing

- **Story image.** A 1080 x 1920 PNG of the visitor's 911 in their paint, their progress and their optional name. The page makes it in the browser before the tap, so the share sheet opens at once. Where a browser cannot share files, the page shows the image to save instead.
- **Plan link.** `?plan=1.<day>.<mask>&by=<name>`. Each mask is base 36 over the item order in `plan.js`. A friend who opens the link can tick the same items, and undo it. A malformed link is ignored.
- **Site address.** It is in the `<head>` of `index.html` (canonical, `og:url`, `og:image`, `og:image:secure_url`, `twitter:image`). Change it there if the host changes.

## Change the item list

Add new items to the end of `PLAN_ITEMS` in `plan.js` and give each a new `data-item` id. Never rename, remove or reorder an id: saved ticks and shared links use them. `bun test` fails when the list and the page disagree.

## The model

Run `bun tools/build-car.js` to rebuild `sports-car.svg` and the build model in `index.html`. The script scales the traced outline to the published Porsche figures: length 4,542 mm, wheelbase 2,450 mm and height 1,302 mm (EU data sheet). The wheels use the standard 992.2 Carrera tyres, 235/40 ZR19 front and 295/35 ZR20 rear. The axle positions use a rear overhang of 1,077 mm, which is a third-party figure that matches the published length and wheelbase. Bricks form the lower body and plates shape the curved top. Each row ends on the real outline.

## The engine

The drawing is a top view with the rear of the car to the left. Cylinders 1 to 3 are on the left bank and 4 to 6 on the right bank. The firing order is 1-6-2-4-3-5, one firing every 120 degrees, and opposed pairs 1/4, 2/5 and 3/6 reach their outer dead centre together. The bore and stroke are scaled from 91.0 mm by 76.4 mm. Porsche does not publish the connecting-rod length, so the drawing uses a common rod-to-crank ratio. The animation runs at 30 crank turns a minute so each firing is easy to follow.

Printed items and promotional giveaways in the checklist are possibilities remembered from past visits, not guaranteed event inclusions. Event details (gates, parking, taxi codes, programme times) come from the official Icons of Porsche site and its preliminary programme, checked on 19 November 2026. Food, drinks, artwork and official merchandise may cost extra.
